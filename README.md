# 鲸鱼余额 · DeepSeek 余额小组件 + 桌面鲸鱼娘

桌面上摆一个 2x1 的小组件，一眼看到 DeepSeek 还剩多少钱，点一下立刻重拉；
另加一只可以拖着到处跑的鲸鱼娘桌宠，戳一下会说话。

## 怎么换成你能装的 APK

1. 建一个 GitHub 仓库（Public / Private 都行）
2. 把这个文件夹里的东西整个传上去（`.github` 是隐藏目录，别漏，Windows 记得开显示隐藏文件）
3. 传完自动开始编译，仓库页面上方点 **Actions** → 等绿的勾
4. 点进那次运行，最下面 **Artifacts** 里下 `whale-balance-apk.zip`，解压就是 `app-debug.apk`
5. 传到手机装上（会提示"未知来源"，允许一下就好）

也可以手动跑：Actions 页面 → `Build APK` → `Run workflow`。

## 装完怎么用

### 小组件

1. 打开 App，填 DeepSeek 的 API Key（`sk-` 开头），点存好啦
2. 回桌面长按空白 → 小组件 → 找「鲸鱼余额」
3. 拖到桌面，搞定

更新时间是系统最短 30 分钟一次，想急着看就点一下小组件。

### 桌宠

1. App 里点「召唤鲸鱼娘到桌面」
2. 第一次会跳系统设置，允许「显示在其他应用上层」（不同手机叫法略有差别：
   悬浮窗 / 显示悬浮窗 / 在其他应用上层显示）
3. 回来再点一次按钮，鲸鱼娘就浮在屏幕上了
4. 按住能拖着走；轻戳一下会喷水、冒一句话
5. 想收回去：点 App 里的「收回鲸鱼娘」，或者点通知栏那条

## 说明

- Key 只存在手机本地 `SharedPreferences`，不往外发，除了发给 DeepSeek 官方接口
- 用的是 `assembleDebug` 编的调试包，可以直接装，不能上应用商店（本来也不上）
- 只读余额接口，不消耗额度
- 桌宠的立绘现在是代码画的（`WhalePetView.kt`），想换成自己的图，把 `onDraw` 换成
  `canvas.drawBitmap(...)` 再丢张 png 进 `res/drawable` 就行
- 桌宠是前台服务，通知栏会有一条常驻通知，这是 Android 8 以后的要求，避免被系统杀掉
